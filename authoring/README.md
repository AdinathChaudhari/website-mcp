# authoring/

Minter guidance served by the `guide(topic)` MCP tool. Each `<topic>.md` here is a topic:
`core`, `testing`, `pagination`, `search`, `publication`, `page-tools`. `README.md` is not a topic.

Add a topic by adding a file; the tool lists the directory. Writes get their guide in a later phase.
Original text, informed by the structure of the MIT-licensed Pomerado authoring guides; nothing is copied.
